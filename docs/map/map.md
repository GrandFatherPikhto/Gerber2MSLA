## 2.2. Потоки

**Тестовые маски (П4, П5а, П5б):**
```
gerber2msla masks bars|grid|square|plate --screen-px 5760x3600 --pixel-um 34x34 -o out/mask.png
  cli:      разбор флагов и взаимоисключений (--widths-mm | --widths-px, --line-mm | --line-px, …)
  patterns: мм → целые пиксели своей оси → Figure (пиксели + строки отчёта + предупреждения);
            plate: рамка + одна метка + bars слева + grid справа, проверка «влезает в рамку»
  masks:    размещение списка фигур (центр или --at) → проверка пересечения/экрана →
            метка одной фигурой или в рисунке → --mirror/--invert на всю картинку → PNG
  stdout:   отчёт «заказано → фактически» и таблица «фигура → угол и размер»; stderr:
            предупреждения; код 2 — отказ
```

**Файл принтера (план П2, П3):**
```
gerber2msla write --template real.px6s mask.png -o out.px6s --exposure-s 60 [--light-pwm 255]
  px6s: шаблон читается, машинное остаётся байт в байт, заменяются слой, оба времени, число слоёв, превью
gerber2msla dump file.px6s [-o layer.png]
  cli_px6s: read_file -> _dump_lines -> stdout (версия, станок, разрешение и пиксель, оба
            времени, нижние слои и слои, подъёмы и скорости, адреса блоков); -o -> слой 0 PNG
            — оракул круга PNG → px6s → PNG
gerber2msla dose MASK.png --template real.px6s -o out/dose --exposure-s 15,20,25
gerber2msla dose MASK.png --template real.px6s -o out/dose --series 15 35 5
  dose: лесенка времён (список ИЛИ геометрия) -> имя {prefix}_{s:.1f}s.px6s ->
        write_file на каждое время (второго пути записи нет)
  stdout: таблица «файл → обычное и нижнее» из ПРОЧИТАННЫХ файлов + сколько записано
```

Круг проверки: PNG → `.px6s` → `dump` → PNG пиксель в пиксель; поля, которые не должны меняться, — байт в
байт как в шаблоне.

## 2.3. Словарь

| термин | значение |
|---|---|
| экран | ЖК-матрица принтера: 5760 × 3600 px, поле 195.84 × 122.4 мм (профиль UVtools/PrusaSlicer) |
| пиксель | 34.0 × 34.0 мкм по профилю; экран светит ЦЕЛЫЕ пиксели, поэтому рисунок задаётся в пикселях |
| шаг | размер одного пикселя по оси (`pixel_x_mm`, `pixel_y_mm`); оси независимы |
| фигура (`Figure`) | рисунок в собственных пикселях + строки отчёта, которые к нему относятся |
| метка | буква F в верхнем левом углу рисунка: ножка слева, перекладины вверх-вправо; зеркало и переворот видны на пластине без микроскопа |
| полярность | что считать засвеченным: по умолчанию белое — линии (негативный резист), `--invert` меняет |
| зеркало | отражение готовой картинки по X; делает только по флагу `--mirror`, сама утилита не отражает |
| отклонение | разница между заказанной в мм шириной и нарисованной; больше 10 % — объявляется строкой `warning:` |
| группа | в `bars`: `--lines` линий ширины `w` с промежутком `w` |
| блок | в `bars`: горизонтальный (линии вдоль X) или вертикальный (вдоль Y); каждый квадратный в мм |
| пластина | одна засветка, на которой лежат ВСЕ тесты: рамка, метка F, `bars`, `grid`; по умолчанию заготовка 70 x 78 мм |
| поле | `--margin-mm`: отступ от края пластины до рамки (по умолчанию 2 мм) |
| рамка | контур квадрата П5а на пластине, со сторонами по осям (`plate - 2·margin`) |
| половины | места фигур внутри рамки: `bars` — левая, `grid` — правая; между ними и рамкой не меньше 1 мм |
| шаблон | настоящий файл принтера, сделанный слайсером: источник всего машинного (подъёмы Z, скорости, служебные блоки) |
| нижний слой | слой 0 однослойного файла; принтер светит его временем НИЖНИХ слоёв, поэтому оба времени равны `--exposure-s` |
| `display_mirror_x` | признак профиля экрана: слайсер отражает картинку по X; что делает файл — выясняется по описанию формата, проверяется меткой F |
| превью | уменьшенная маска в файле принтера; для глаз, не для геометрии |
| RLE | кодирование слоя `pw0Img`: «серость + длина серии» (план П1) |
| клетка | один тест; «28 клеток» — строки таблицы перенесённых тестов, считая параметры `parametrize` |
