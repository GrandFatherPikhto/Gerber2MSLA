Gerber2MSLA, 23.10.2026, по образцу Gerber2LDI `docs/map/map.md`. «План П…» — хозяин назначен планом
`techdocs/handoff/deepseek/plan_2026_10_23_png2px6s.md`, кода ещё нет; по мере появления — заменить на

## 2.1. Одно правило — одно место

| правило | хозяин | состояние | замечание |
|---|---|---|---|
| размер в ЦЕЛЫХ пикселях своей оси | `gerber2msla/masks.py` (`_quantised`) | план П4 | `n = round(size / pitch)`, округление, а не усечение; `n = 0` при нужном размере — `Refusal` с числом и осью; ЕДИНСТВЕННОЕ место привязки |
| реальный размер нарисованного в мкм | `gerber2msla/masks.py` (`_actual`) | план П4 | одна строка отчёта на ось: «N px along X = M um» |
| буква F: форма, размер, линии | `gerber2msla/masks.py` (`marker_pixels`) | план П4 | несимметрична по обеим осям — этим и читается зеркало/переворот; сторона в мм, линии в пикселях |
| метка в углу рисунка, рисунок рядом | `gerber2msla/masks.py` (`add_marker`) | план П4 | поверх рисунка не рисуется: испортила бы то, что рисунок меряет; рисунок только сдвигается |
| размещение, зеркало и полярность всей картинки | `gerber2msla/masks.py` (`compose`) | план П4 | `--at` / центр; «не влезает» — отказ с размерами в мм И пикселях; `--mirror` = `fliplr`, `--invert` = `255 −` |
| запись PNG маски | `gerber2msla/masks.py` (`write_mask`) | план П4 | режим `L`, ровно экран, отчёт в текстовый кусок `msla_tests` |
| `bars`: группы линий, квадратные блоки | `gerber2msla/patterns.py` (`build_bars`) | план П4 | промежуток = ширине, порядок ширин — оператора; блок X-линий слева, Y-линий справа |
| `grid`: сколько линий влезает | `gerber2msla/patterns.py` (`build_grid`) | план П4 | ЕДИНСТВЕННОЕ место счёта: первая линия вплотную к краю, линия только целиком, остаток у дальнего края — промежуток |
| ширина из заказа в пиксели (мм или пиксели) | `gerber2msla/patterns.py` (`_width_pixels`) | план П4 | пиксельный заказ — ровно `n`; мм — через `_quantised` |
| отклонение мм-заказа больше 10 % | `gerber2msla/patterns.py` (`_deviation`) | план П4 | порог строгий (`> 0.10`); у пиксельного заказа отклонения нет |
| две ширины в одно `n` | `gerber2msla/patterns.py` (`_duplicates`) | план П4 | предупреждение, не отказ |
| разбор командной строки | `gerber2msla/cli.py` (`build_parser`) | есть | тонкий: флаги, типы argparse, вызов одного обработчика; геометрии здесь нет |
| имя и версия утилиты | `gerber2msla/cli.py` (`PROG`, `_version`) | есть | `gerber2msla <version>`; без установленных метаданных — `unknown` |
| формат `px6s`: чтение и запись | `gerber2msla/px6s.py` | план П2, П3 | всё машинное — из шаблона байт в байт; пишем только описанные поля |
| описание формата `px6s` | `docs/format_px6s.md` | план П1 | у каждого поля — ссылка на файл и метод UVtools; код UVtools (AGPL) не переносится |

## 2.2. Потоки

**Тестовые маски (П4):**
```
gerber2msla masks bars|grid --screen-px 5760x3600 --pixel-um 34x34 -o out/mask.png
  cli:      разбор флагов и взаимоисключений (--widths-mm | --widths-px, --line-mm | --line-px, …)
  patterns: мм → целые пиксели своей оси → Figure (пиксели + строки отчёта + предупреждения)
  masks:    метка F в угол рисунка → размещение на экране (центр или --at) → --mirror/--invert → PNG
  stdout:   отчёт «заказано → фактически»; stderr: предупреждения; код 2 — отказ
```

**Файл принтера (план П2, П3):**
```
gerber2msla write --template real.px6s mask.png -o out.px6s --exposure-s 60 [--light-pwm 255]
  px6s: шаблон читается, машинное остаётся байт в байт, заменяются слой, оба времени, число слоёв, превью
gerber2msla dump file.px6s [-o layer.png]
  px6s: поля заголовка в stdout, слой 0 в PNG — оракул круга PNG → px6s → PNG
```

Круг проверки: PNG → `.px6s` → `dump` → PNG пиксель в пиксель; поля, которые не должны меняться, — байт в
байт как в шаблоне.

## 2.3. Словарь

| термин | значение |
|---|---|
| экран | ЖК-матрица принтера: 5760 × 3600 px, поле 195.84 × 122.4 мм (профиль UVtools/PrusaSlicer) |
| пиксель | 34.0 × 34.0 мкм по профилю; экран светит ЦЕЛЫЕ пиксели, поэтому рисунок задаётся в пикселях |
| шаг | размер одного пикселя по оси (`pixel_x_mm`, `pixel_y_mm`); оси независимы |
| фигура (`Figure`) | рисунок в собственных пикселях + строки отчёта, которые к нему относятся |
| метка | буква F в верхнем левом углу рисунка: ножка слева, перекладины вверх-вправо; зеркало и переворот видны на пластине без микроскопа |
| полярность | что считать засвеченным: по умолчанию белое — линии (негативный резист), `--invert` меняет |
| зеркало | отражение готовой картинки по X; делает только по флагу `--mirror`, сама утилита не отражает |
| отклонение | разница между заказанной в мм шириной и нарисованной; больше 10 % — объявляется строкой `warning:` |
| группа | в `bars`: `--lines` линий ширины `w` с промежутком `w` |
| блок | в `bars`: горизонтальный (линии вдоль X) или вертикальный (вдоль Y); каждый квадратный в мм |
| шаблон | настоящий файл принтера, сделанный слайсером: источник всего машинного (подъёмы Z, скорости, служебные блоки) |
| нижний слой | слой 0 однослойного файла; принтер светит его временем НИЖНИХ слоёв, поэтому оба времени равны `--exposure-s` |
| `display_mirror_x` | признак профиля экрана: слайсер отражает картинку по X; что делает файл — выясняется по описанию формата, проверяется меткой F |
| превью | уменьшенная маска в файле принтера; для глаз, не для геометрии |
| RLE | кодирование слоя `pw0Img`: «серость + длина серии» (план П1) |
