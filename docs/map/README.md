# docs/map/ — карта проекта Gerber2MSLA

По образцу Gerber2LDI (`docs/map/`): рабочая карта, только по-русски, в git. Карта — подсказка, а не
истина: расходится с кодом — прав код, а карту поправить.

- **`index.md`** — указатель, СОБРАННЫЙ ИЗ КОДА: модули (строки всего / кода, первая строка docstring,
  пометка `⚠ >800`), публичное API, кто кого импортирует, сторожа `tests/repo/`. Генерируется, руками не
  правится, в git не идёт.
- **`map.md`** — «одно правило — одно место» (хозяин каждого правила), потоки, словарь, где лежат данные.
- **`structures.md`** — что лежит в чём: экран, фигура, ширина, шаблон и слой `px6s`.
- **`contracts.md`** — сквозные договоры. Читать ДО задания и ДО приёмки: действуют, даже если задание их
  не назвало.

## Перегенерация `index.md`

Linux / macOS:
```sh
.venv/bin/python tools/project_map.py
```
Windows:
```bat
.venv\Scripts\python.exe tools\project_map.py
```

`tools/project_map.py` — копия генератора Gerber2LDI (коммит `544122d`, 21.10.2026; тот, в свою очередь,
копия KiCadStamp). Отличаются списки пакетов (`PACKAGES`, `INTERNAL_TOP`) и строка `generated: <дата>`:
на машине без git SHA в шапке будет `unknown`, и отставание карты видно по дате.

Перед заданием сверь SHA в шапке `index.md` с `git rev-parse HEAD` (git нет — сверь дату генерации с датой
последней правки кода). Отстал — перегенерируй. После задания, которое добавило, переименовало или удалило
модуль либо публичную функцию, — перегенерируй; поменялось правило или поток — поправь `map.md` в том же
заходе.

**Состояние на 23.10.2026:** каркас (П0 плана `png2px6s`): пакет `gerber2msla` с CLI без команд, тесты
каркаса, карта. Модули `masks`, `patterns`, `px6s` — план П4, П1–П3; строки `map.md` и `structures.md` с
пометкой «план» заменяются на `файл:строка` по мере появления кода.
