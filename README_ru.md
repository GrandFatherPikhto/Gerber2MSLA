# Gerber2MSLA

Засветка фоторезиста плат на MSLA-принтере (Anycubic Photon Mono X 6Ks): маска в точных
пикселях экрана становится файлом принтера, позже плата — из гербера.

ЖК-экран засвечивает ЦЕЛЫЕ пиксели, поэтому утилита работает в пикселях экрана — на этом
принтере 5760 x 3600, 34 мкм на пиксель по профилю UVtools/PrusaSlicer (это профиль, а не
проверенный паспорт). Файл принтера — однослойный `.px6s`; к принтеру ничего не отправляется,
лазера здесь нет.

Состояние: тестовые маски, привязанные к пикселям (`bars`, `grid`), работают как
`gerber2msla masks …`; конвертер (PNG → `.px6s`) — следующий шаг плана
`techdocs/handoff/deepseek/plan_2026_10_23_png2px6s.md`.

## Тестовые маски

```sh
.venv/bin/gerber2msla masks bars --screen-px 5760x3600 --pixel-um 34x34 \
    -o out/bars.png --widths-px 6,5,4,3,2,1
.venv/bin/gerber2msla masks grid --screen-px 5760x3600 --pixel-um 34x34 \
    -o out/grid.png --width-mm 50 --height-mm 40 --line-px 6 --gap-px 4
```

* `--screen-px` и `--pixel-um` **обязательны**: выдуманное число хуже отказа. Пиксель
  может быть неквадратным — две величины, по оси.
* каждая ширина становится `n = round(ширина / шаг)` пикселей СВОЕЙ оси, и отчёт печатает
  запрошенную ширину рядом с ФАКТИЧЕСКОЙ: 0.100 мм на пикселе 34 мкм — это 3 px =
  0.102 мм. Именно фактическое число и будет на пластине.
* `--widths-px 6,5,4,3,2,1` — та полоска, с которой стоит начинать на этом экране: шесть
  РАЗНЫХ ступеней по 34 мкм. Список в миллиметрах 0.2/0.15/0.1/0.08/0.06/0.05 дал бы
  6, 4, 3, 2, 2, 1 — две одинаковые группы, о чём утилита и предупреждает.
* ширину можно заказать в миллиметрах или в ЦЕЛЫХ ПИКСЕЛЯХ; эти две формы исключают друг
  друга. Промах мм-заказа больше 10 % объявляется: «0.050 mm along Y is drawn as
  34.0 um (-32 %)».
* каждый рисунок несёт букву **F** в верхнем левом углу, узор начинается правее неё;
  F несимметрична по обеим осям, поэтому зеркальная засветка (ножка справа) или
  перевёрнутая (перекладины внизу) видна на пластине. `--no-marker` выключает метку.
* белое — засвеченный пиксель: по умолчанию белые ЛИНИИ (негативный резист), `--invert`
  меняет это местами, `--mirror` отражает готовую картинку по X.
* отчёт — экран, пиксель, ширины запрошенные и фактические, зеркало, полярность —
  пишется ещё и в текстовый кусок PNG `msla_tests`, чтобы файл помнил, что он такое.

Как довезти PNG до принтера (путь со слов Claude, Денис ещё не проверял): открыть в
**UVtools** любой однослойный файл этого принтера, заменить слой импортированной
картинкой, выставить время засветки и сохранить. Маска задаёт геометрию, время засветки —
дозу.

## Установка (для разработки)

```sh
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
```

## Тесты

```sh
.venv/bin/python -m pytest -q -rsf -p no:cacheprovider -n auto
.venv/bin/python -m pytest -q -rsf -p no:cacheprovider -n auto --reverse
```
